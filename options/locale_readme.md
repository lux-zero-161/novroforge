# NovroForge translations

All translations are stored in directories `locale` and `locale_next`.

* `locale` contains legacy translations in the INI format
* `locale-next` contains newer translations in the JSON format

## Translators

* read [Localization documentation](https://novroforge.xyz/docs/next/contributor/localization/)
* improve translation on [Codeberg Translate](https://translate.codeberg.org/projects/novroforge/)
* translations submitted through pull requests to this repository will not be accepted

## Other contributors

* read [Base localization documentation](https://novroforge.xyz/docs/next/contributor/localization/english/)
