The default config for `database.MAX_OPEN_CONNS` changed from 0 (unlimited) to 100 to avoid problems if it exceeds the limit by the database server. If you require high concurrency, try to increase this value for both NovroForge **and your database server**. [`Limit database max connections by default`](https://codeberg.org/novroforge/novroforge/pulls/3383)
